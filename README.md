# fuchs-image-optimizer

Локальное приложение для сжатия JPEG, PNG и WebP. Выберите одно или несколько
изображений, просмотрите миниатюры и задайте общие настройки сжатия.
Одна кнопка запускает последовательную обработку всей партии. Для каждого файла
показаны размеры и отдельная ссылка для скачивания. Ошибка одного изображения
позволяет продолжить обработку остальных.

В карточке каждого файла исходник показан сверху, а сжатое изображение — под ним
на компьютере и телефоне.
«Скачать изображение» сохраняет один результат. После завершения обработки
«Скачать все» собирает успешные результаты в ZIP на вашем компьютере.
При совпадении имён в архиве добавляются числовые суффиксы.

## Установка и запуск

Установите Node.js 24 LTS с npm. В каталоге проекта выполните команды.

```sh
npm ci
npm start
```

Приложение откроет страницу в браузере по умолчанию. Если окно не открылось,
перейдите по адресу из терминала. Порт выбирается автоматически при каждом запуске.
Оставляйте терминал открытым во время работы. Для остановки нажмите Ctrl+C.

После установки зависимостей приложение работает без подключения к интернету.
Изображения обрабатываются на вашем компьютере. Файл результата сохраняется
через браузер, исходное изображение остаётся у пользователя.

## Настройки и ограничения

- Входные и выходные форматы — JPEG, PNG и WebP. Можно выбрать несколько статичных изображений.
- Если браузер не смог показать миниатюру, в строке файла появится сообщение о недоступности предпросмотра.
- Для всех форматов ползунок «Качество» задаётся от 0 до 100, начальное значение — 80.
  Значение сохраняется при смене формата. Ползунок доступен с клавиатуры.
- Для JPEG и WebP меньшее значение снижает детализацию. Значение 0 передаётся кодеку как 1.
- Для PNG сжатие всегда без потерь. Меньшее значение задаёт более интенсивное сжатие
  и может увеличить время обработки. Значения 0, 50 и 100 соответствуют уровням PNG 9, 5 и 0.
- При сохранении в JPEG прозрачные области заливаются белым.
- Применяется ориентация EXIF, исходные метаданные удаляются.
- Размер входного файла — до 16 МиБ, число пикселей — до 24 миллионов.
  Размер результата ограничен 32 МиБ.
- На загрузку и обработку отведено по 30 секунд. Одновременно обрабатывается один файл.
  Другие вкладки во время обработки получат сообщение о занятости.
- Иногда результат занимает больше места. Страница покажет увеличение и предложит скачивание.
